# 英国零售数据集清洗与可视化分析

## 项目简介
基于 Python Pandas 对 54 万条英国零售交易数据进行数据清洗与可视化分析，揭示销售趋势与业务特征。

## 技术栈
- **语言**：Python
- **工具**：Pandas, Matplotlib
- **数据源**：Kaggle - Online Retail Dataset (541,909 条记录)

## 项目流程
1. **数据读取**：处理原始 CSV 编码问题（ISO-8859-1）及路径映射。
2. **数据清洗**：
   - 剔除退货订单（InvoiceNo 以 'C' 开头）
   - 过滤负单价、负数量的异常交易
   - 缺失值检查（CustomerID 缺失 13 万余条）
3. **特征工程**：新增 `TotalPrice` 列（Quantity * UnitPrice）。
4. **可视化分析**：按月份聚合销售额，绘制 2010-2011 年度销售趋势折线图。

## 分析结论
- 全年销售额在 **2011年11月达到峰值**（约 150 万英镑），符合圣诞购物季的周期性特征。
- 2 月为销售低谷，整体呈现明显的零售季节性规律。

## 文件说明
- `data.py`：完整的数据分析脚本。
- `monthly_sales.png`：月度销售额趋势图。

## 进阶维度分析
*注：原始数据包含邮费（POSTAGE）及手动调整（Manual）记录，计算真实商品销售额时应予以剔除。*

- **客户价值**：Top 10 客户贡献了显著的超高销售额（最高单客超 27 万英镑），验证了典型的“二八定律”，核心客户维护至关重要。
- **商品洞察**：在剔除邮费等非实物商品后，`REGENCY CAKESTAND 3 TIER` 等家居装饰品是真正的核心利润商品。
